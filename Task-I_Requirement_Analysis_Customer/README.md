# Task I - Requirement Analysis and Customer Database

## Aim
To understand the requirements of an E-Commerce Order Management System and create a simple Customer table.

## Main entities
- Customer
- Product
- Category
- Seller
- Inventory
- Orders
- Order Details
- Payment
- Review
- Rating

## Customer table
The Customer table stores basic information about customers.

### Important fields
- customer_id - unique ID of the customer
- customer_name - customer's name
- email - customer's email
- phone - customer's phone number
- address - customer's address

## SQL file
Run `01_customer.sql` in MySQL.

## Expected learning
After this task, you should understand:
1. What a database requirement is.
2. How an entity becomes a table.
3. How a primary key is used.
4. How customer data is stored.
