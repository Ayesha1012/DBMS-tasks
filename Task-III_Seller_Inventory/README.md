# Task III - Seller and Inventory Management

## Aim
To store seller information and maintain product inventory.

## Tables
- Seller
- Inventory

## Relationships
- A seller can sell products.
- Inventory connects a seller with a product.
- The quantity field stores available stock.

## Operations included
- Add sellers
- Add seller products
- Check available and unavailable products
- Generate an inventory report

## SQL file
Run `01_seller_inventory.sql` after Task II.
