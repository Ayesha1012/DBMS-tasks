# E-Commerce DBMS Tasks - Beginner Version

This repository contains seven beginner-friendly DBMS tasks for an E-Commerce Order Management System.

## Folder structure

1. `Task-I_Requirement_Analysis_Customer`
2. `Task-II_Product_Category`
3. `Task-III_Seller_Inventory`
4. `Task-IV_Order_Management`
5. `Task-V_Payment_Transactions`
6. `Task-VI_Product_Review_Rating`
7. `Task-VII_SQL_Query_Implementation`

## Software
These SQL files are written in simple MySQL syntax.

## How to run
Run the tasks in order because later tasks use tables created earlier.

Start with Task I. It creates the `ecommerce_db` database and Customer table.

Then run the SQL file inside each task folder.

## Note
The queries intentionally use simple SQL so that a beginner can understand each operation.
