# Task IX - Sales and Customer Analytics System

## Aim
To use SQL aggregate functions and prepare simple sales reports.

## Topics covered
- COUNT(), SUM(), AVG(), MIN() and MAX()
- Total sales
- Customers with the highest purchase amount
- Best-selling products
- Category-wise sales

## SQL file
Run `ix.sql` after completing the earlier tasks.

## Beginner note
Aggregate functions calculate a result from several rows. For example, SUM adds values and AVG finds their average.
