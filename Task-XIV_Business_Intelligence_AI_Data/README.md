# Task XIV - Business Intelligence and AI Data Preparation

## Aim
To create reports and prepare simple customer and product data for analysis.

## Topics covered
- Analytical reports
- RANK() and ROW_NUMBER()
- Customer segmentation
- Feature extraction
- Preparing data for an AI model

## SQL file
Run `xiv.sql` in MySQL 8.0 or a compatible version that supports window functions.

## Beginner note
Window functions calculate a result across related rows without combining them into one row. The segmentation and features here are simple examples for learning, not a production AI model.
