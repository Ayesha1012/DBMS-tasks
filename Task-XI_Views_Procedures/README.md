# Task XI - Database Automation using Views and Procedures

## Aim
To practise database objects that can make repeated work easier.

## Topics covered
- Views
- Stored procedures
- Functions
- Testing database objects

## SQL file
Run `01_views_procedures.sql` in MySQL 8.0 or a compatible version.

## Important note
The file uses DELIMITER to define stored programs. Run the full file in a MySQL client that supports DELIMITER, such as MySQL Workbench.

## Beginner note
A view saves a query definition. A procedure stores SQL steps that can be called when needed. A function returns a value.
