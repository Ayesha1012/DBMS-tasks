# Task VIII - Database Relationship Analysis using Joins

## Aim
To understand how different tables in an E-Commerce database can be connected using SQL JOINs.

## Tables used
- Customer
- Product
- Orders
- Order_Details
- Payment

## JOINs covered
- INNER JOIN
- LEFT JOIN
- RIGHT JOIN

## What this task does
1. Shows customer order details.
2. Shows the products included in orders.
3. Shows payment information for orders.
4. Displays customer purchase history.
5. Creates simple multi-table reports.

## SQL file
Run `01_joins.sql` after completing the previous tasks.

## Beginner note
A JOIN is used when information is stored in different tables and we want to see the related information together.
