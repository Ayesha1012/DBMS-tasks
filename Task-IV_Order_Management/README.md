# Task IV - Order Management

## Aim
To store customer orders and the products included in each order.

## Tables
- Orders
- Order_Details

## Relationship
One customer can place many orders.

One order can contain many products.

`Order_Details` connects orders and products.

## Operations included
- Insert orders
- Add ordered products
- Modify order details
- View customer order history

## SQL file
Run `01_orders.sql` after Task II.
